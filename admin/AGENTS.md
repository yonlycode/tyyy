# yo-port Admin — Standards & Coding Context

**Current date:** 2026-08-18

## Overview
Standalone **desktop** admin CMS (Wails) for the `yo-port` site. Edits the Markdown articles in the GitHub repo and commits to `main`, which triggers the site's GH Pages rebuild. Ships as a native desktop app: a Go backend whose methods are bound directly to an embedded React SPA (no HTTP server, no REST API).

## Stack & Conventions
- **Desktop shell:** Wails v2 (`github.com/wailsapp/wails/v2`), configured in `wails.json`, entrypoint `main.go`
- **Backend:** Go 1.26. Bound methods live on the `App` struct in `pkg/app/app.go`; only **exported** methods are bound
- **GitHub API:** `google/go-github/v60` — note v60 quirks:
  - `RepositoryContentFileOptions.Content` is `[]byte` (already unencoded, do NOT base64)
  - `RepositoryContent.GetContent() (string, error)` decodes base64 automatically
  - `CreateFile`/`UpdateFile`/`DeleteFile` return `(*RepositoryContentResponse, *Response, error)`
- **Frontmatter:** `adrg/frontmatter` (YAML `---` blocks, compatible with the site's `gray-matter`)
- **JSON shape:** Go structs must carry BOTH `yaml` and `json` tags (lowercase) so the frontend receives `title`, `description`, `date`, `tags`, `published` etc.
- **Frontend:** React 19, Vite 7, TypeScript 5, Yarn 1.22 (corepack)
- **Bindings:** auto-generated by `wails build`/`wails dev` into `frontend/wailsjs/` (gitignored). Re-import path is `../../wailsjs/go/app/App` from `src/services/`. `frontend/wailsjs` must stay in `tsconfig.json` `include`.
- **Markdown preview:** `remark` + `remark-html`

## Defaults
- Articles dir: `web/content/articles`
- Images dir: `web/public/images`
- Branch: `main`
- Owner/repo: `yoannfort/yo-port`

## Content contract (aligned with `web/src/lib/md.ts`)
Each article is `slug.md` with frontmatter `title`, `description`, `date`, `tags`, `published` (defaults to `true`). `published !== false` = visible on the site.

## Bound methods (frontend calls these only, via `wailsjs/go/app/App`)
| Method | Notes |
|---|---|
| `GetConfig()` | token never serialized back |
| `SetConfig(content.Config)` | token kept in memory only |
| `ListArticles()` | list metadata |
| `GetArticle(slug)` | full article |
| `SaveArticle(*content.Article)` | save/publish (commit) |
| `DeleteArticle(slug)` | delete |
| `UploadMedia(fileName, dataB64)` | returns markdown ref |

Errors are returned to the frontend as rejected Promises — surface sentinel errors from `pkg/content/article.go` (`ErrConflict`, `ErrNotFound`, …).

## Build / run
- Dev: `cd admin && wails dev` (HMR, opens native window)
- Prod: `cd admin && wails build` → `admin/build/bin/yo-port-admin.app`
- Makefile targets at repo root: `admin-install`, `admin-dev`, `admin-build`, `admin-run`

## Rules
- Always re-run `go vet ./...`, `gofmt -w .`, and `tsc` (`yarn build`) after changes; regenerate bindings via `wails build` if a bound method signature changed.
- The PAT must never be logged, written to disk, or returned to the frontend.
- Keep `pkg/content/article.go` frontmatter keys (yaml + json) in sync with `web/src/lib/md.ts`.
- Don't commit `frontend/wailsjs` or `build/` — both gitignored.
- Only add **exported** methods to `App` that you intend to expose; unexported helpers stay private.
