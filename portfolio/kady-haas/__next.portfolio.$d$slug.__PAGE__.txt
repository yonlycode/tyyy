<p>Pour la plupart des entreprises, l'accès à l'IA générative rime avec une triple dépendance :</p>
<ol>
<li><strong>Une fuite structurelle des données stratégiques</strong> (devis, contrats, bilans) vers des serveurs sous juridiction américaine (Cloud Act, FISA 702).</li>
<li><strong>Une facture imprévisible</strong>, indexée sur la consommation de tokens et le bon vouloir des éditeurs d'API propriétaires.</li>
<li><strong>Une vulnérabilité réseau totale</strong> : connexion coupée ou API en outage, l'activité s'arrête.</li>
</ol>
<p>Le SaaS vous loue votre propre capacité de calcul. <strong>Le HaaS (Hardware-as-a-Service) vous l'installe.</strong></p>
<p><strong>Kaly</strong> est la box : une appliance d'IA locale clé en main, livrée préconfigurée, qui tourne sur site. <strong>Kady</strong> est l'ouvrier numérique qui l'habite : l'agent qui fait le travail métier — gestion documentaire, classification, synthèse — sans qu'aucune donnée ne quitte les locaux.</p>
<h2>Ce Qui Est Réel Aujourd'hui</h2>
<p>Soyons directs sur l'état d'avancement : <strong>le produit est en construction, la waitlist est ouverte.</strong> Pas de clients en production, pas de ROI mesuré, pas d'audit de sécurité publié. Ce qui existe :</p>
<ul>
<li><strong>Le panel de gestion Kaly</strong> : application Go (stdlib) + HTMX + MongoDB — waitlist, leads, suivi du parc de box, événements, ingestion. Développement actif, déployable en conteneur.</li>
<li><strong>Le design system Kady-UI</strong> : librairie de web components (Storybook publié) pour une pâte graphique commune sur tous nos produits.</li>
<li><strong>Les bancs d'essai matériels</strong> : inférence locale mesurée sur AMD Strix Halo (les chiffres sont dans l'article halogen-flash de ce blog, mesures réelles et publiées).</li>
<li><strong>La grille tarifaire</strong> : abonnement HaaS au forfait mensuel, dégressif selon la capacité de la box — affichée sur le site, sans astérisque.</li>
</ul>
<h2>L'Architecture Visée</h2>
<pre><code>┌──────────────────────────────────────────────┐
│              BOX KALY (sur site)             │
│  ┌────────────────┐   ┌───────────────────┐  │
│  │ Moteur          │   │ Kady : agent      │  │
│  │ d'inférence     │◄──┤ métier (docs,     │  │
│  │ llama.cpp       │   │ mails, synthèse)  │  │
│  │ (CPU/APU/GPU)   │   └───────────────────┘  │
│  └────────────────┘                           │
│  Chiffrement du stockage · réseau local       │
│  Interface web locale (Go + HTMX)             │
└──────────────────────────────────────────────┘
</code></pre>
<ul>
<li><strong>Matériel</strong> : la config définitive de la box de production est en cours d'arbitrage (profil d'usage, budget, densité de modèles). Nous ne publions pas de spec sheet fantaisiste : quand la config sera arrêtée, elle sera publiée avec ses mesures réelles.</li>
<li><strong>Inférence</strong> : llama.cpp et modèles quantifiés open weights. Pas de fine-tuning maison annoncé à tort — l'adaptation passe par le contexte, les skills et les workflows de l'agent.</li>
<li><strong>Interface</strong> : serveur Go + HTMX, accessible sur le réseau local du client.</li>
<li><strong>Pilotage</strong> : le panel Kaly central suit l'état des box (événements, pings) — opt-in, métriques techniques, jamais le contenu métier du client.</li>
</ul>
<h2>Ce Que Le HaaS Change Pour Un Client</h2>
<ul>
<li><strong>Souveraineté</strong> : les documents sensibles ne quittent pas le boîtier. C'est la promesse centrale, et elle est structurelle — pas une option dans les CGU.</li>
<li><strong>Facture plate</strong> : forfait mensuel, pas de compteur de tokens.</li>
<li><strong>Résilience</strong> : la box travaille même internet coupé.</li>
<li><strong>Maintenance déléguée</strong> : c'est nous qui gérons la machine, ses modèles et ses mises à jour — c'est le « as a Service » du HaaS.</li>
</ul>
<h2>Où On En Est</h2>
<p>Le panel est en développement, la landing est publique, la waitlist est ouverte. Les premiers pilotes seront documentés ici avec des chiffres vrais — débits, consommations, économies constatées — pas des pourcentages sortis d'un chapeau.</p>
